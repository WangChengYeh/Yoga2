效能監測CPU · GPU

主要任務占觀測時間累積秒平均 ms／次較基準 ms
任務時間明細
TaskCPU／GPU開始秒提交秒完成／結束秒耗時 ms提交後延遲 ms
秒數為本頁 performance 時間軸；worker 子步驟以收到結果時重建大致起訖。

依 task 起訖估算 CPU loading；GPU task 只計收到完成通知的區間，CPU 平行任務重疊累加，可超過 100%（200% 約為兩個執行緒的 task 時間）；GPU 重疊只計一次，兩者不能相加為 100%；排隊另外列出。非 CPU 核心／整機 GPU 使用率。關閉面板仍保留最近 30 分鐘；資料隨除錯包匯出。背景暫停觀測，缺少資料標示 —。

瀏覽器會協商可用 FPS。AI 運算與辨識依序執行，AI 忙碌時降低 3D 幀率；辨識速度仍受裝置限制。

影像平時只在手機分析；按「回報問題」才會上傳相機圖與場景截圖至 GitHub。首次需下載姿勢模型；預設不啟用人像去背。

站位與觀察範圍

面向前鏡頭，手機保持直立，移到能拍全身的位置。相機原始畫面不顯示；關節看不清楚時會停止動作判斷，未看見的關節不參與判斷。

只觀察雙手上舉、側傾方向與展臂高度，不代表姿勢正確或安全；單一前鏡頭無法確認開胸深度。切到背景會關閉相機；語音輸入預設嘗試啟用，仍需允許麥克風權限。
