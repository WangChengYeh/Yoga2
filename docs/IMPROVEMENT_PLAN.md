# Yoga2 改善規劃（修訂）

語音已正常，以維持穩定與回歸檢查為主。下一階段聚焦記憶體穩定性、真人／教練比例與 AI 動作判斷。

| 優先級 | 項目 | 目標版本與範圍 |
| --- | --- | --- |
| P0 | DRAM／GPU 診斷 | v0.9.20：採樣、任務快照、ZIP、前次摘要，實際無法量測的項目明確標示 |
| P0／P1 | WebLLM 記憶體、WebGL／WebGPU 排程 | v0.9.22：依證據調整載入／釋放、FPS 與競爭；待測目標一般 30–60、AI 推論 15–30 FPS，非已驗證最佳值 |
| P1 | 真人比例 | v0.9.21：全身依身高、半身依實際教練臉大小、臉部高度對齊、多幀固定及手動重校準 |
| P1 | 骨架分析 | v0.9.23：程式先算角度／方向／對稱差異，LLM 再產生文字，驗證上舉／側伸／展臂三種動作 |
| P2 | 降級與復原 | v0.9.22：停止非必要工作，AI 失效仍可練習；不可假定降低 FPS 就會減少權重記憶體 |
| P2 | 長時間驗收 | 各版持續：實機三十分鐘測試與不同 context 對照 |

## 待驗收門檻（尚非實測結果）

- [ ] iPhone 13，1K 連續三十分鐘練習不崩潰。
- [ ] 4K／16K 的模型載入、推論與 GPU 失效可由紀錄區分。
- [ ] ZIP 包含最近五分鐘可取得的記憶體診斷；剛啟動／背景／節流／容量上限有明確說明。
- [ ] 半身臉大小與 Luna 誤差不超過 10%，並有實際畫面驗證。
- [ ] AI 可辨識三個動作主要偏差，有數值與人像回歸佐證。
- [ ] 語音維持目前正常行為，通過回歸與實機確認。

目前只實作 v0.9.20 診斷。後續比例、排程、復原與動作分析不因這份規劃而標為完成。
