## 日誌維護方式

- 功能與行為變更寫入 CHANGELOG；問題調查寫入 ISSUES；實際執行結果寫入 VALIDATION，避免三份各自複製整段敘述。
- 記錄日期、版本、症狀或指令、可觀察證據與結論；沒有證據時明記「待確認」。發布與本機測試分開記錄。
- 不提交原始執行 log、權杖、私鑰、一次性 code、個人帳號或完整問答。測試輸出、推論產物與本機環境保留在已忽略的路徑。
- 發布後更新驗證日誌的 CI／Pages 結果；手機體驗需另外記錄裝置、瀏覽器、權限及重現步驟，不能用模擬測試代替。
